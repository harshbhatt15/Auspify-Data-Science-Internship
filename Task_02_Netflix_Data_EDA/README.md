# Netflix Data Exploratory Data Analysis (EDA)

## 1. Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix dataset to discover content distribution, country-wise contributions, ratings, genres, movie durations, and content addition trends.

## 2. Objectives

- Analyze Movies and TV Shows distribution.
- Identify top content-producing countries.
- Explore Netflix content ratings.
- Analyze release-year trends.
- Study movie duration patterns.
- Identify popular genres.
- Analyze yearly content additions.

## 3. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 4. Key Findings

1. Movies account for approximately 69.7% of the dataset, while TV Shows account for 30.3%.
2. The United States ranks first in country-wise content associations, followed by India.
3. TV-MA is the most common content rating.
4. 2018 has the highest number of titles by release year, with 1,144.
5. Most movie durations are concentrated around 80–120 minutes.
6. International Movies is the most frequent genre.
7. 2019 recorded the highest number of content additions, with 2,013 titles.

## 5. Visualizations

## 7. Conclusion

The analysis reveals that Netflix's dataset contains a strong representation of movies, substantial American and Indian content, and a high concentration of mature and teen-oriented ratings. The catalogue shows significant growth in content additions between 2015 and 2019.
